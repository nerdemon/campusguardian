CampusGuardian AI: An Autonomous Multi-Agent Smart Campus Ecosystem

CampusGuardian AI is a fully autonomous, multi-agent intelligent system that acts as the central nervous system of a modern university campus. By unifying real-time IoT telemetry, AI-driven risk evaluation, network-layer attendance tracking, and a Retrieval-Augmented Generation (RAG) knowledge engine under a single intelligent platform, the system eliminates four chronic institutional inefficiencies — energy waste, manual attendance, reactive security, and inaccessible policy knowledge — without requiring human intervention.

Problem Statement

Modern university campuses operate as fragmented, data-rich but insight-poor environments. Classrooms run HVAC and lighting at full capacity in empty rooms, costing institutions millions annually in preventable energy waste. Faculty lose 5–10 minutes per class to manual roll-calls. Security teams must monitor hundreds of camera feeds simultaneously with no intelligent triage. Campus policy documents remain locked in PDFs — inaccessible, unsearchable, and unactioned. No unified system currently exists to perceive, reason, and act across all these domains in real time.

Proposed Solution — Four Autonomous Pillars
🌿 Smart Climate & Energy Engine

Monitors real-time occupancy and environmental telemetry. When a room is empty but HVAC/lights are active, the system autonomously flags waste and triggers energy-saving protocols — targeting up to 40% reduction in campus energy expenditure.

📡 Autonomous Academic Ledger

Eliminates manual attendance via network-layer MAC address proximity detection. When a student's device connects to classroom Wi-Fi during a scheduled lecture, they are instantly logged as present — creating tamper-proof, timestamped records automatically.

🛡️ AI Security & Risk Evaluator

Every room is continuously evaluated by Google Gemini 2.5 Flash, returning a structured risk verdict — Safe, Warning, or Critical — with actionable recommendations in under 5 seconds. After-hours motion in empty labs is instantly classified as a high-severity intrusion.

🧠 Institutional Knowledge RAG Agent

An n8n-automated pipeline ingests campus policy PDFs into a ChromaDB vector store using Gemini Embedding API. Students query campus rules, timetables, and policies in natural language and receive grounded, cited answers fused with live sensor context.

Technical Architecture

The system is built on a Digital Twin architecture where a Python-based sensor simulator (replaceable with physical IoT hardware with zero backend changes) continuously injects environmental telemetry into a FastAPI backend. This backend persists state to Supabase (PostgreSQL) and employs an Agentic Router Pattern — routine data is logged instantly while anomalies trigger the Gemini 2.5 Flash reasoning engine for contextual evaluation. A React + Vite dashboard provides real-time visualization. The full stack is deployed via Vercel (frontend) with the AI inference layer running on cloud services — no proprietary hardware required.

Innovation & Novelty

Unlike single-feature smart campus solutions, CampusGuardian AI is the only system that unifies all four institutional domains under one autonomous AI reasoning layer. The Agentic Router Pattern ensures low latency for standard telemetry while reserving LLM inference for genuine anomalies — a cost-efficient and scalable design. The Digital Twin architecture makes the platform production-ready from day one: the live hackathon demo uses simulated sensors, but physical IoT integration requires no backend changes. Every element of the demo dashboard is wired to live backend services and a real cloud database — this is not a prototype.
